# proxmox/r730xd/scripts

Verbatim copies of `/root/scripts/*.sh` on `pve`. The host is the running
copy; this is the reviewable one and the source for a reinstall.

`sas-disks.sh`, `sas-health-check.sh`, `sas-spindown.sh` and
`spindown-drift-check.sh` are **not** here — they are generated by
[`../install-spindown.sh`](../install-spindown.sh), which stays the single
source of truth for them.

Schedule: [`../etc/crontab`](../etc/crontab). What each job is for:
[`../README.md`](../README.md).

⚠️ Every `hc-ping.com` URL is replaced with `REPLACE-ME-SEE-PRIVATE-NOTES`
— this repo is public and those URLs are capability tokens. Real values are
in `/root/PRIVATE-NOTES.md` on pve, which restic now backs up. Restore
copies these scripts, then paste the three UUIDs back.

`backup-synology-home.sh` is in no crontab — it was the Synology→pve pull,
run by hand. `synology-home` is now the live source, not a mirror, so the
script would overwrite it with `--delete`. Kept for reference; do not
schedule it.
